# AI

为系统提供基础 AI 文本对话能力

- 基于 AG-UI 的流式文本对话
- 支持对话列表、详情、重命名、置顶、删除
- 支持消息编辑后重发、删除、清空和停止生成
- 支持默认模型、供应商、模型和快捷短语管理
- 支持多供应商文本模型和附件输入

本插件只保留基础对话能力

如需 MCP、空间、知识、客户端等完整 Buddy 能力，请前往插件市场安装 AI Buddy：https://docs.fba.wu-clan.cc/fastapi_best_architecture_docs/marketplace.html

## 插件类型

- 应用级插件

## 配置说明

插件目录下 `plugin.toml` 的 `[settings]` 中包含以下内容：

```toml
[settings]
AI_HTTP_MAX_RETRIES = 5
```

在 `backend/core/conf.py` 中添加以下内容：

```python
##################################################
# [ Plugin ] ai
##################################################
# 基础配置（in plugin.toml）
AI_HTTP_MAX_RETRIES: int = 5
```

## 配置项说明

- `AI_HTTP_MAX_RETRIES`：控制模型供应商 HTTP 请求的最大重试次数

## 使用方式

1. 安装并启用 AI 插件后重启后端服务
2. 安装对应的前端 AI 插件，通过后台管理维护供应商、模型和快捷短语
3. 创建 AI 供应商，再同步或创建对应模型
4. 配置默认助手模型
5. 在前端 AI Chat 中发起文本对话并维护会话历史

## 卸载说明

- 卸载插件后，建议同步移除相关配置
- 如前端页面或业务流程已依赖 AI 对话、默认模型、模型、供应商、快捷短语等能力，请同步清理对应集成
